## Versioning

The versioning follows a simple pattern:

| Minimum OS Version Suppoprted | Ansible Version | Patchversion |
| --- | --- | --- |
| Python3 -> 3 | Ansible 13 -> 13 | First working version -> 1 |

This will equal to version `3.13.1`.
